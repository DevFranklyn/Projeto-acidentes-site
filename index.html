🚛 Acidentes em Rodovias Federais – 2025

Dados públicos da PRF • Limpeza Python • Visualizações Vega-Lite

Este site apresenta 9 análises visuais em gráficos, utilizando dados extraídos do dataset limpo de acidentes de 2025. Ferramentas utilizadas no processo são: Google colaboratory utilizando a biblioteca Pandas (Python) para limpeza dos dados, github como repositorio de dados, Observable HQ utilizando a biblioteca Vega-Lite para trahnsformar os dados em graficos por meio de javascript.

Projeto – Tratamento e visualização de dados.
Fonte: Polícia Rodoviária Federal (Dados Abertos) 2025.
