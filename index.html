🚛 Acidentes em Rodovias Federais – 2025

Dados públicos da PRF • Limpeza com Python • Visualizações Vega-Lite

Este site apresenta 9 análises visuais, utilizando dados extraídos do dataset limpo de acidentes de 2025. As ferramentas utilizadas no processo foram:

  • Google Colaboratory + Pandas – limpeza e preparação dos dados
  • GitHub – repositório do dataset e hospedagem do site
  • ObservableHQ + Vega-Lite – criação dos gráficos
📊 Projeto acadêmico – Tratamento e visualização de dados
