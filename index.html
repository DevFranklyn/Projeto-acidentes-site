Parte 3 do projeto: Google Colaboratory com Pandas e graficos com ObservableHQ.
Este projeto aplica limpeza, analise e visualizacao de dados em um conjunto de dados reais, os acidentes registrados pela Policia Rodoviaria Federal (PRF) nas rodovias federais brasileiras durante o ano de 2025.

Parte 1: Carregamento dos dados brutos da PRF (584 mil linhas) no Google Colab com pandas. Limpeza: remocao de duplicatas, valores nulos e selecao das 17 colunas mais relevantes. Geracao de graficos iniciais e exportacao do dataset limpo para CSV.

Parte 2: Importacao do CSV limpo no ObservableHQ via fetch. Criacao de 9 graficos interativos com Vega-Lite abordando: horario, dia da semana, estado, causas, tipo de acidente, classificacao, rodovia, sexo e idade. Cada grafico acompanhado de interpretacao e conclusao.

Parte 3: Criacao de um site estatico com HTML, CSS e JavaScript, publicacao do site no GitHub Pages. Adicao dos colaboradores ao repositorio.

  • Google Colaboratory + Pandas – limpeza e preparacao dos dados
  • GitHub – repositorio do dataset e hospedagem do site
  • ObservableHQ + Vega-Lite – criacao dos graficos
