Parte 3 do projeto Google colaboratory com Pandas e graficos com Obersavable HQ.

Este projeto aplica limpeza, análise e visualização de dados em um conjunto de dados reais, os acidentes registrados pela Polícia Rodoviária Federal (PRF) nas rodovias federais brasileiras durante o ano de 2025.

Parte 1: Carregamento dos dados brutos da PRF (584 mil linhas) no Google Colab com pandas. Limpeza: remoção de duplicatas, valores nulos e seleção das 17 colunas mais relevantes. Geração de gráficos iniciais e exportação do dataset limpo para CSV.

Parte 2: Importação do CSV limpo no ObservableHQ via fetch. Criação de 9 gráficos interativos com Vega-Lite abordando: horário, dia da semana, estado, causas, tipo de acidente, classificação, rodovia, sexo e idade. Cada gráfico acompanhado de interpretação e conclusão.

Parte 3: Criação de um site estático com HTML, CSS e JavaScript, publicação do site no GitHub Pages. Adição dos colaboradores ao repositório.
